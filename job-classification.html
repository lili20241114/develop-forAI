典型工作流程拆解示例

📋 任务：整理牛奶区货架
步骤1

推黄色推车到3号冷柜

  • • 找到推车（黄色贴纸标记）
  • • 推到冷柜前停下
  • • ✅ 完成后点"下一步"
步骤2

拿取货架左侧牛奶

  • • 左手拿
  • • 从最左边开始
  • • ✅ 完成后点"下一步"
步骤3

按日期从左到右摆放

  • • 看日期：月/日
  • • 早的放左边
  • • ✅ 完成后点"下一步"
步骤4

放回推车，准备下一个区域

典型工作流程拆解示例

📋 任务：清洗餐盘
步骤1

戴好手套和围裙

  • • 红色手套（左手）
  • • 蓝色手套（右手）
  • • ✅ 完成后点"下一步"
步骤2

打开水龙头（绿色标记）

  • • 找到绿色把手
  • • 向左转
  • • ✅ 完成后点"下一步"
步骤3

洗碗（洗洁精在红色瓶）

  • • 挤1下洗洁精
  • • 从左到右洗每个碗
  • • 碗变干净后放旁边沥水架
步骤4

冲水（3秒）

  • • 每个碗冲3秒
  • • 放蓝色沥水架
步骤5

完成后关水（向右转）

典型工作流程拆解示例

📋 任务：图像标注 - 框选车辆
步骤1

打开标注软件

  • • 双击电脑桌面"标注助手"图标
  • • 输入工号登录
  • • ✅ 登录后点"开始"
步骤2

选择任务类型

  • • 点击"图像标注"
  • • 点击"车辆框选"
  • • ✅ 进入标注页面
步骤3

框选车辆

  • • 看到图片中的汽车/摩托车
  • • 按住鼠标左键拖动画框
  • • 框住整辆车后松开鼠标
步骤4

选择车辆类型

  • • 面包车 → 点击🚐
  • • 小汽车 → 点击🚗
  • • 卡车 → 点击🚛
步骤5

提交并继续

  • • 点击"提交"
  • • 自动进入下一张图片
  • • 完成10张后休息
